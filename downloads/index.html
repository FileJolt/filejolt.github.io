Install the portable application correctly.

Download the ZIP, extract all contents into a writable folder, and run the application EXE from the extracted directory. Do not launch it directly from the ZIP. Both apps require Microsoft Edge WebView2 Runtime.

i
About Windows publisher warnings.

NexLoad and ReelShift are official FileJolt releases, but their Windows executables are not digitally code-signed. Windows may display an “Unknown publisher” or Microsoft Defender SmartScreen warning. This does not automatically mean the software is unsafe. Download only from the official GitHub release links above and verify the ZIP’s SHA-256 checksum before running it.
