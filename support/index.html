FREQUENT QUESTIONS
Do I need an account to download?

No FileJolt account is required. Windows builds are available through GitHub Releases.

Are the applications installers?

NexLoad and ReelShift are each available as portable ZIPs; extract the complete folder before launching either EXE. FileJolt Setup is also available if you prefer a guided offline installation.

How do I verify my download?

Open the checksum on the Downloads page. In PowerShell, run Get-FileHash -Algorithm SHA256 with your downloaded ZIP filename and compare the output.

Can I run these apps on macOS or Linux?

No. The listed releases are designed for Windows x64, with each application's exact supported Windows version shown on its product page.

What if a download link stops working?

Open the corresponding release page on GitHub for the authoritative release asset and update information.

Can ReelShift convert or compress video files?

No. ReelShift works with existing media and subtitle filenames and locations. It does not transcode, recompress, or download metadata from an online database.

Can ReelShift undo every rename?

Undo is available only for eligible changes recorded while local history was enabled. Keep backups of important media and review the proposed changes before applying them.

Does NexLoad work with every video site?

No single downloader supports every site or format. URL analysis, available media formats, and playlist behavior depend on the source and bundled downloading tools. Only download media you are permitted to save.
